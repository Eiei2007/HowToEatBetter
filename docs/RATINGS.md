# 评级口径

每条有六组标签：性价比、证据、收益类型、花钱、时间、毅力；修改日期独立列出。

## 性价比

极高：针对较重要风险，且通常操作成本低。高：合理收益与执行负担较平衡。一般：可选优化，优先级低于基本饮食和安全。均为编辑判断，需要按原有习惯、预算与健康情况重新理解；不把寿命与钱混成一个分数。

## 证据

- A（绿色）：所写具体结局有随机试验或其系统综述依据。样本小、时间短、失访和不确定性仍须写明，不意味着正式评为高质量。
- B（黄色）：主要是观察研究及其汇总。能支持关联，不能保证因果；地区、人群、混杂因素与反向因果须考虑。
- C（灰色）：指南、公共卫生操作或编辑执行建议。也可引用原则的随机研究作为背景，但不能把它当作具体操作的直接试验。

这里没有完成独立系统综述、逐项偏倚评估或正式 GRADE 质量评价。C 不等于不重要，例如生熟分开不需要高风险喂食试验来证明必要性；A 也不等于结论确定，例如早餐综述的试验较短、质量有限。

## 收益类型

“寿命”只在引用确实涉及死亡结局时使用，仍需明确人群与观察/干预性质。“健康”可涉及体重、血压、营养或感染风险，不自动换算成多活几年。“钱”“时间精力”可来自明确的算账或执行策略，示例须注明为假设。

## 成本

“不花钱”表示通常不增加购买预算，不表示没有用电、清洁或机会成本。“少”“多”不设全国统一价格。顺手、几分钟等是操作负担估计，习惯、人群和家庭条件不同会改变难度。每条成本与备注比短标签更重要。
