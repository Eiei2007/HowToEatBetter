# 来源与核实记录

本版按主题检索国内外原始研究、系统综述与官方指南，主要使用期刊网站、PubMed、Cochrane 和卫生/食品安全部门。检索日期：2026-11-05。不是穷尽文献的系统综述，也未完成双人筛选、偏倚评估或正式 GRADE 分级。

检索重点：糖与体重、钠与血压及卒中、全谷/蔬果/坚果/肉蛋与长期风险、减重方案、特殊饮食、家庭食品安全。优先记录直接结局，不把替代指标自动换成死亡收益。机构新闻稿用于解释同一研究，不计作额外独立试验。
