# 好好吃饭：高性价比饮食指南

用普通食物、有限预算和能坚持的做法，改善中国日常饮食。

这是一份备选清单，不是自律考试。先挑一两件最容易做的事。首版包含 **6 章、22 条建议**，覆盖买菜做饭、外卖食堂、聚餐和食品安全。

**[在线阅读与筛选](https://eiei2007.github.io/HowToEatBetter/)**

## 怎么看等级

| 性价比 | 本项目的判断口径 |
| --- | --- |
| 极高 | 直接处理重要风险，通常花费少、执行负担低 |
| 高 | 有合理收益，但要结合原来的饮食和执行成本 |
| 一般 | 可选优化，优先级低于基本饮食和食品安全 |

等级是编辑判断，不是医学评级，也不是精确的寿命或收益排名。原本已经做到的人，继续改善的空间可能很小。价格随城市、季节和渠道变化，因此不编造全国统一的每日花费。

**每条六组标签：性价比、证据等级、换回什么、花钱、花时间、要毅力。**

- **A 级（绿色）：** 已核对的随机试验或其系统综述支持所写结局；具体操作可能是原则的应用。
- **B 级（黄色）：** 长期收益主要来自观察性研究或其汇总，不能直接证明因果。
- **C 级（灰色）：** 指南、公共卫生共识或编辑执行建议，暂未核实直接干预研究。

这是本项目的简化阅读分组，不是正式 GRADE 质量评级。不能因为引用指南就自动标 A。“寿命”仅指研究涉及死亡风险，不表示能保证多活几年；血压或体重改善归“健康”。“不花钱”指通常无需额外购买，不表示没有水电或机会成本。成本和毅力均为编辑估计，详细条件见每条备注。

## 适用范围

面向一般健康成年人。孕期、儿童、老人营养不良、食物过敏，以及肾病等有特殊营养需求的人，应采用针对性建议。这里不承诺减重结果，不计算“多活几年”，也不替代诊疗。
